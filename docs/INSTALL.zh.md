# 📦 安装与使用

[← 返回首页](../README.md) · [English](INSTALL.en.md) · [下载页面](https://github.com/d-dev0101/open-sea-for-codex/releases)

Open Sea 是搭配 **官方 Codex 桌面客户端** 使用的独立本地控制端。请先确认官方 Codex 能正常打开，再安装 Open Sea。使用安装包 **无需 npm 登录、Node.js 或终端命令**。

本文对应 `v0.1.0-beta.1` Beta。平台文件、签名信息和测试范围，以 [Release 实际附件与说明](https://github.com/d-dev0101/open-sea-for-codex/releases)为准；`Source code.zip` / `Source code.tar.gz` 是源码，不是安装包。

## Mac 安装

### 1️⃣ 选对芯片版本

打开 **苹果菜单 → 关于本机**，然后在 [Releases](https://github.com/d-dev0101/open-sea-for-codex/releases) 选择：

| “关于本机”显示 | 下载文件 |
| --- | --- |
| Apple M 系列芯片 | `mac-arm64` 的 `.dmg` 或 `.zip` |
| Intel 处理器 | `mac-x64` 的 `.dmg` 或 `.zip` |

只下载该次 Release 实际提供的架构文件。Apple 芯片 Mac 上已由用户确认真实 Codex 的动态海洋与顶部透明导航；Intel Mac 尚未完成手动实机验证。

### 2️⃣ 安装 Open Sea

打开 `.dmg`，把 **Open Sea for Codex** 拖到“应用程序”，再打开。若下载的是 `.zip`，先解压，再把应用移入“应用程序”。

当前 Mac 包通过 ad-hoc 签名校验，但没有 Apple 开发者签名或公证，因此首次打开可能出现系统提示。

<details>
<summary><strong>macOS 阻止打开时怎么处理？</strong></summary>

先确认文件来自本仓库对应的 Release，并核对该版本说明。对于你确认可信且未被篡改的文件，尝试打开后，可在 **系统设置 → 隐私与安全** 查看是否有针对该应用的“仍要打开”选项。按系统流程确认即可；不同 macOS 版本的提示可能不同。

如果提示文件损坏或包含恶意内容，请停止安装并反馈。不要关闭 Gatekeeper、移除隔离属性或修改全局安全设置。[Apple 官方打开应用说明](https://support.apple.com/en-us/102445)

</details>

### 3️⃣ 应用到 Codex

在 Open Sea 中选择“海洋”，点击 **启动带皮肤的 Codex**。如果新开的官方 Codex 窗口出现登录页，完成登录并等待主界面；无需反复点击启动。

预览可以先调好波浪、日光和不透明度。连接成功后，修改会应用到受管理的 Codex 窗口。

## Windows 安装（实验性）

当前 Windows 路径面向官方 `OpenAI.Codex` Microsoft Store 客户端。请先安装并正常打开官方客户端。

1. **下载**：在 [Releases](https://github.com/d-dev0101/open-sea-for-codex/releases) 选择实际提供的 `win-x64` `.exe`。
2. **安装**：运行安装向导，再从开始菜单打开 **Open Sea for Codex**。
3. **应用**：点击 **启动带皮肤的 Codex**。新窗口如要求登录，完成登录后等待主界面。

**验证边界：** Windows 已有构建和自动化检查，但尚未完成原生 Windows 手动验证。安装包成功生成不等于整套客户端集成已经验证。

Windows 包尚无发布者签名，可能出现 SmartScreen 提示；请先核对来源、版本说明与文件信息。组织策略也可能阻止安装或 Store 客户端的独立启动。遇到限制时保留错误提示并反馈，不要关闭系统防护或使用管理员命令强行绕过。[Microsoft 的 SmartScreen 说明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)

## 日常使用

**入口就在菜单栏 / 系统托盘。** 点击 Open Sea 图标，可打开设置、切换背景、导入视频、暂停和恢复。关闭控制面板窗口只会隐藏；选择 **退出 Open Sea** 才会退出。

| 想做什么 | 操作 |
| --- | --- |
| 🌊 使用动态海洋 | 选择“海洋”；默认波浪 56、日光 55 |
| 🫧 调整通透感 | 拖动“玻璃不透明度”：15–90%，默认 40%；数值越小越透明 |
| 🖼️ 换静态背景 | 选择“极光”“沙丘”“海岸”，或导入自己的图片 |
| 🎞️ 使用本地视频 | 点击“导入动态视频”，选择本机文件；视频静音循环播放 |
| ⏸️ 暂停动态 | 点击“暂停动态背景”，再次点击继续 |
| 🌐 切换语言 | 右上角“中” / `EN` |

**文件支持：** 图片支持 PNG、JPEG、WebP，最大 10 MiB；视频支持 MOV、MP4、M4V、WebM，最大 2 GiB。超大像素图片也可能被拒绝；宽图可能在本机缩小并转为 JPEG，因此不保证保留透明区域。视频容器受支持不代表所有编码都能播放，尤其是 HEVC；失败时面板会提示，可换其他视频或切回海洋。

### 预览与真实客户端有什么区别？

控制面板使用 **真实海洋渲染器 + 16:10 示例 Codex 布局**，包含侧栏、工作区和圆角输入框，使用示例内容，不读取真实聊天。拖动不透明度、波浪和日光，可即时预览效果。

预览能运行不代表已连接 Codex，也不代表所有客户端界面都已经验证。真实客户端以连接状态及实际显示为准。

视频短暂缓冲时，预览会保留当前画面。隐藏或最小化面板只会暂停预览；重新打开后继续，不改变 Codex 背景的播放设置。手动选择的暂停状态会保留。

## 使用 Mac 动态壁纸

1. **打开系统设置**：在“Mac 动态壁纸”区域点击 **去系统下载 ↗**。
2. **下载喜欢的壁纸**：在 macOS 墙纸设置中选择并等待下载完成。
3. **返回 Open Sea**：面板恢复焦点时会自动查找，也可点击 **刷新**。
4. **点击应用**：选择列表中的壁纸。已有 Codex 连接时会应用背景；尚未连接时，再点击 **启动带皮肤的 Codex**。

列表只显示本机找到且通过完整性检查的视频，结果取决于 macOS 版本和下载情况。Open Sea 的按钮打开系统墙纸设置，下载由 macOS 处理；它不会直接从 Apple CDN 下载视频。

### 第一次为什么需要“准备动态壁纸”？

部分系统视频使用高帧率 HEVC，播放器不能直接可靠播放。Open Sea 使用随 Mac 应用提供的本机转换工具，生成 **最高 1080p、30 fps 的静音 H.264 播放副本**。完整片长保留，系统原文件不变；面板会显示准备进度。

对依赖信息与时间线检查通过的高帧率视频，会减少不必要的解码；其他视频自动使用兼容路径。在一次约 5 分钟的 4K/240fps 壁纸测试中，耗时从 110.5 秒降到 36.0 秒，实际速度仍取决于你的设备和视频。[完整验证记录](VALIDATION.md)

副本保存在本机私有目录；原文件未变化、缓存可用时，再次选择直接复用，更新控制端也不会要求全部重转。使用安装包无需额外安装 ffmpeg、Swift 或开发工具。

Apple 视频不会随仓库或安装包分发，也不会被皮肤上传。Windows 用户可通过 **导入动态视频** 使用自己的视频，没有 macOS 系统设置入口。[素材与隐私说明](SECURITY.md)

## 更新已有版本

1. **退出旧控制端**：从菜单栏 / 托盘选择 **退出 Open Sea**，等待图标消失。仅关闭窗口会让旧版继续运行。
2. **安装新版**：安装到原位置，再打开 Open Sea。保留应用数据目录，设置与导入的媒体可以继续使用。
3. **重新应用**：点击 **启动带皮肤的 Codex**。控制端会检查并尝试重连此前管理的 Codex 窗口，再应用新版皮肤。

如果仍显示旧效果，先点击 **恢复原界面**，确认成功后再应用。连接已失效时，保存工作后退出 **由 Open Sea 启动的 Codex 实例**，再从新版控制端启动。不要结束其他 Codex 窗口。

## 看懂状态

| 面板状态 | 含义与下一步 |
| --- | --- |
| 控制器已就绪 | 面板可用；不表示已经连接 Codex |
| 等待主界面 | 等待客户端加载；只有出现登录页时才需要登录 |
| 正在初始化海洋图形 / 静态海洋背景 | 已连接，动态效果正在准备或暂时不可用；无需重新登录 |
| 正在本机准备动态壁纸…% | 首次转换系统视频；等待完成，下次可复用缓存 |
| 正在加载本地视频 | 正在准备首帧；无需再次启动或登录 |
| 皮肤已在 Codex 中显示 | 已识别主界面并应用皮肤 |
| 视频背景未能播放 / 皮肤渲染失败 | 查看具体提示，换背景或调整后重试；不是登录请求 |
| 界面预览 · 未连接客户端 | 当前只有独立预览；打开 Open Sea 应用来启动或恢复 Codex |

多窗口时，失败或静态回退会优先显示。遇到连接或启动错误，按具体提示确认官方客户端已安装、受管理窗口仍在运行。

## 首次登录与连接方式

Open Sea 用独立的浏览器配置启动受管理的官方 Codex 窗口，因此可能需要首次登录。普通启动仍沿用现有 `CODEX_HOME`；未设置时由 Codex 使用自己的默认目录。**独立浏览器配置不等于聊天数据隔离。**

皮肤通过验证后的本机回环 Chrome DevTools Protocol（CDP）连接应用到主界面，不修改官方应用包或内容安全策略（CSP）。CDP 本身有操作页面的能力；回环地址限制网络可达范围，但不对同一电脑上的其他进程提供身份认证。不要将此调试端口转发或暴露到其他电脑。[连接与安全边界](SECURITY.md)

## 恢复与退出

- **只恢复外观**：点击 **恢复原界面**，移除 Open Sea 添加的背景与样式。
- **退出控制端**：从菜单栏 / 托盘选择 **退出 Open Sea**。它会在限定时间内尝试移除皮肤并断开连接，但不会关闭 Codex。
- **完全结束这次受管理启动**：恢复皮肤 → 退出 Open Sea 启动的 Codex 实例 → 按正常方式重新打开 Codex。退出该实例才会关闭它的调试端口。

连接中断或超时可能使清理不完整。若恢复按钮暂不可用，等当前操作结束；若连接已经中断，保存工作、退出受管理实例并正常重开即可。不要结束无关进程。
